# Carte du jour CHEFJEAN

Application d'édition de la carte du jour : l'équipe décoche ce que la boutique n'a pas,
l'application compose la carte A4 (noir sur blanc) et l'imprime en PDF.

- `index.html` — l'application, autonome (polices et pictogrammes embarqués, aucune connexion nécessaire).
- Mise à jour : le fichier est régénéré chaque matin à 9h depuis la carte du site et publié ici.

Page : https://chefjean.github.io/chefjean-carte/
